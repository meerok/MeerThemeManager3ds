# Sample theme: Neon Sunset

A complete theme made with MtM3, with original artwork and music you can study or reuse.

| File | |
|---|---|
| `body_LZ.bin` | Scrolling top wallpaper, page-flip bottom wallpaper, folder art, neon interface colors, 4 sound effects |
| `info.smdh` | Name, description, author, icon |
| `preview.png` | 412 × 480 preview |
| `bgm.bcstm` | 8-second looping chiptune (loop point at 4 s) |

**Try it:** copy this folder to `/Themes` on your SD card and install it with Anemone3DS, or open it in MtM3 (**File → Open Theme Folder…**) to see how it's made.

`source-files/` holds the original artwork and audio that went into it (all made for this project and free to reuse).
